2025-11-30 — Building A Space Game

I added a new subpage to my site — a small browser game I'm calling "Space Game." I know, incredibly creative.

Working on it was honestly a lot of fun. It pulled me in way more than I expected. But it was also a lot of work: adding features, rewriting pieces, fixing things that broke, and adjusting elements that didn't feel right. The deeper I got, the more little details I realized I needed to change or refine.

I built the whole thing with Cursor, using its Agent mode, and that part was surprisingly interesting and easy to work with. The "Ask" mode especially stands out — it shows you a lot of information about the code, what's happening, and why, which makes building and debugging a lot more transparent.

There are still issues I haven't solved yet — saving high scores, getting it to work smoothly on mobile devices, and a few smaller adjustments that keep popping up. But none of that takes away from the fun of building it.

If friends — or anyone playing it — have ideas, requests, or things they'd like me to add or change, I'd really like to hear them. Feedback helps the game evolve.

So I'll keep improving it from time to time and see where this game ends up.
